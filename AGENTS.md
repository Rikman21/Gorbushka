# Локальные правила Codex для этого проекта

- После завершения значимых изменений самостоятельно делать деплой/публикацию изменений в Git, если пользователь не попросил обратное.
- В финальном сообщении после проделанной работы писать, какие команды нужно выполнить в терминале на сервере.
- Если для деплоя или пуша нужны доступы, токены, подтверждение опасного действия или сетевой доступ, сначала запросить разрешение/данные у пользователя.
